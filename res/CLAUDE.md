# res/

Runtime assets loaded by Heaps resource system. Access via `Res.*` (compile-time checked).

## Directories

| Directory | What | When to Read |
|-----------|------|--------------|
| `audio/` | Sound effects and music | Adding audio assets |
| `data/` | JSON configs (tower stats, enemy stats, nest definitions) | Tuning game balance, adding entity types |
| `sprites/` | PNG images for game graphics | Adding or replacing visual assets |

Note: Subdirectories are stub directories (contain only `.gitkeep`). CLAUDE.md files will be added when assets are added.
